## What is not covered

1. **AC-3, the restart of the decoder after a hostile-class outcome.** A truncated HEIC ends as a clean `Corrupt` (the job is
   dead, the container keeps serving, its start time is unchanged: this part runs and passes). A hostile-class exit (a
   descendant process left alive, a watchdog abort, a memory kill) cannot be produced by any file the API accepts. The
   decoder's own suite owns it (IT-10-14 and IT-10-15, with `test_freeze`), and it needs the decoder test image. Replay:
   when E-19's container suite runs on this stack, add the leg here or close AC-3 on that suite's result.
2. **AC-71, the kill during the input fetch and during the output post.** Each phase lasts milliseconds for the small
   fixtures, so an external SIGKILL is a race, not a test. Only the kill while a job is inside the decoder is deterministic
   (the decoder container is frozen with `docker pause`). Replay: a hold in the stack, either a throttled worker listener
   (a slow input fetch) or a test build of the supervisor that pauses between the decoder's output and the post. Neither
   exists; both are a design decision for E-20 or E-31, not for this task.

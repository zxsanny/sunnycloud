# Test Data Parameters

Representative data sets used to test the system. Files are generated by scripts during the test step (seeded, reproducible); none are stored in git. Clip and photo sets are cut from freely licensed sources or synthesized with ffmpeg and ImageMagick.

| Set | Contents | Purpose |
|-----|----------|---------|
| many-small | 10,000 files of 1 KiB to 1 MiB in a folder tree up to 5 levels deep | listing, small-file upload, sync fan-out, desktop first scan |
| listing-10k | one folder with 10,000 entries | AC-6 |
| photos | 100 JPEG photos of 12 MP, plus 20 HEIC, 10 with EXIF rotation | thumbnails, camera backup |
| photos-bulk | 10,000 JPEG photos of 12 MP | bulk-import thumbnails |
| clip-1080-sdr | one 10-minute 1080p 30 fps SDR H.264 clip (non-compliant bitrate) | AC-11 reference A |
| clip-4k-hlg | one 10-minute 4K 30 fps HEVC HLG clip | AC-11 reference B |
| clip-compliant | one 3-minute compliant H.264 High 1080p AAC MP4 | never re-encoded |
| clip-mixed-100 | 100 mixed phone clips, including rotated, variable frame rate, audio-only | derived storage, watchdog |
| big-file | one 5 GiB file; one 50 GiB sparse-generated file | resumable upload, 50 GiB limit |
| tree-100k | 100,000 small files | desktop watcher load |
| tricky-names | files differing only by case, Unicode NFC and NFD names, a Windows reserved name, a 300-character path, names with bidi characters, `..` segments, a symlink and a junction pointing outside the root, alternate data stream names | cross-OS naming and hostile-name corpus (40 cases per OS) |
| collide-1000 | 1,000 local files, of which 200 collide with server paths (100 identical content, 100 different) | first-sync merge |
| evicted-100 | tree of 100 cloud-evicted placeholder files (iCloud/OneDrive) among 400 normal ones | AC-32 |
| editor-saves | scripted save-in-place from vim, JetBrains, Word, LibreOffice, KeePassXC | AC-34 |
| redteam-media | SVG and PDF renamed .png, HLS playlist referencing `/etc/passwd`, 30000x30000 PNG, 20 GB sparse video, truncated HEIC | decoder isolation |
| uploads-hostile | html, svg, xml, js, pdf and a polyglot GIF/HTML file | content-serving headers |
| vault-file | one 100 MiB file; one 101 MiB file; empty file; file of exactly N chunks | vault (v1.2) |
| vault-fuzz | 10,000 mutated vault headers | header authentication (v1.2) |
| oauth-mock | a mock identity provider that can return valid and each of 10 invalid callbacks, including an unverified victim email | auth tests |
| phone-fixtures | Android Pixel, Samsung and Xiaomi devices; an Android phone with 5,000 backed-up assets; a library of 50,000 assets | mobile tests |
| backup-set | a populated installation with database dump, blobs and master key | backup/restore/upgrade |

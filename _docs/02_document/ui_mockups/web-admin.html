Default quota

100 GB

Applies to every user without their own quota. The operator sets it in the server configuration (default_quota_bytes); it cannot be changed here.

  • Only current versions of files count. Previews and versions kept for recovery do not.
  • A quota below what someone already uses blocks new uploads and deletes nothing.
  • A quota of 0 means no new data.

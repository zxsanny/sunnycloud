Android backup

Flutter screens of the Android app (17): sign in, backup status and settings. There are two tabs only, Backup and Settings; Android v1.0 does not browse or download files. Kotlin and the shared Rust library do the work; these screens only show its status.

iOS (v1.1) reuses these screens and hides Google and GitHub sign-in unless the server has Sign in with Apple enabled.

1 · Sign in

9:41

sunnycloud

Back up your photos

Photos and videos go to your own sunnycloud server.

Use an address that starts with https://. sunnycloud does not sign in over plain HTTP.

Your browser opens your server's sign-in page with the options that server offers, such as GitHub or Google. Then you come back here with a one-time code.

The address must be https. The app checks it with the server before sign-in; sign-in options come from the server, not from the app.
